# Bundled fonts

Every face shipped here is under the SIL Open Font License 1.1; each family's own copy of the license and
copyright notice is beside it. They are bundled so that a label rendered on one machine renders identically on
another — rasterezpl never substitutes a face.

| face | family / author | file | license |
|---|---|---|---|
| Inter, Inter Bold | The Inter Project Authors (rsms) | `Inter-Regular.ttf`, `Inter-Bold.ttf` | `Inter-OFL.txt` |
| JetBrains Mono | The JetBrains Mono Project Authors | `JetBrainsMono-Regular.ttf` | `JetBrainsMono-OFL.txt` |
| Bebas Neue | Dharma Type (2018 release) | `BebasNeue-Regular.ttf` | `BebasNeue-OFL.txt` |

The OFL permits bundling and redistribution with the license kept; the fonts are not sold on their own.
