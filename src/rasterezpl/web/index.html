Compose — your own labels

Type labels (one per block, blank line between; {n} = running number), or give a list of labels — open a CSV / TSV file or paste a sheet, one label per row, a template saying which columns go where (no template: every column on its own line) — or open an Easy-Mark .pemx. A composed job is a recipe: recent compositions below reloads one, swap the list, print. Pick a layout (a decoration around the text; sample fills its example) and a face — the bundled faces render the same everywhere. A picture (PNG, JPEG, or SVG when the server can render it) goes on the logo, logo-top and image layouts; the badge, qr-left and qr layouts encode the QR data, one code per label (barcode / barcode-below / barcode-only encode the same data as a Code 128 — a rack label whose bars scan to the text under them); clear-qr and clear-image print on the WHOLE self-laminating label (the full-label media is picked for you) — for a tag stuck flat, not one that wraps. The preview is the exact print of the first row and follows every change you make (preview re-renders it now; row picks another); compose saves a job file under composed/ and puts it in the cart.
