Compose — your own labels

Type labels (one per block, blank line between; {n} = running number), or paste rows with a header and a template, or open an Easy-Mark .pemx. Pick a layout (a decoration around the text; sample fills its example) and a face — the bundled faces render the same everywhere. Preview is the exact print; compose saves a job file under composed/ and puts it in the cart.
